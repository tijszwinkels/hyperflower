# Hyperflower

A psychedelic GPU flower: rainbow tunnels, kaleidoscopic petals, and glowing fractal-like detail.
Run it in Hyprsaver or in the browser.

- [Install in Hyprsaver](docs/hyprsaver.md)
- [Install in Omarchy](docs/omarchy.md)
- [Run in your browser](browser/README.md)

The installation guides include instructions for coding agents. The browser demo uses the same `hyperflower.frag` shader, with no external dependencies.

Created as a Companion widget and adapted for [Hyprsaver](https://github.com/maravexa/hyprsaver).
